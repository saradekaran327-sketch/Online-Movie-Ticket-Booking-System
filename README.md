# Online Movie Ticket Booking System

## About the Project
This project is developed using C++ and Object-Oriented Programming concepts.
It allows users to select movies, theatres, shows and seats.

## Features
- Display available movies
- Select a movie
- Select a theatre
- Choose a show date and time
- Display seat availability
- Different seat categories and prices

## Technologies Used
- C++
- Object-Oriented Programming (OOP)

## Concepts Used
- Classes and Objects
- Arrays
- Loops
- Conditional Statements
- Member Functions
